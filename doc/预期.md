**元信息层**

```
文案原文
行业/赛道
目标人群
内容类型：种草/情绪/知识/反转/故事/干货/争议
视频表现：点赞、评论、收藏、转发
钩子类型
痛点
卖点
情绪
结构
结尾行动
```

**拆解层**

```
主题：这条内容讲什么
目标用户：说给谁听
核心痛点：用户为什么会停留
情绪按钮：焦虑、好奇、共鸣、爽感、反差、危机感
开头钩子：一句话如何抓注意力
内容结构：提出问题 -> 放大痛点 -> 给出观点 -> 举例 -> 行动建议
表达技巧：短句、反问、对比、金句、数字、故事化
可复用模板：如果你是____，一定要注意____
适用场景：直播引流/私域成交/课程种草/个人IP
风险点：夸大承诺、违规词、过度焦虑
```

**模板层**

```
结构模板
钩子模板
转折方式
情绪路径
行业话术
用户痛点库
卖点表达库
结尾转化方式
```

**知识库层**

```
原始文案库：保存原文和来源
结构化拆解库：保存每条文案的分析结果
模板库：抽象出来的句式和框架
标签库：行业、情绪、目的、人群、钩子类型
案例库：高表现案例及其原因
禁用库：敏感词、违规表达、不要复刻的内容
```

筛选

```
行业 = 美妆
目的 = 引流
人群 = 25-35岁女性
风格 = 犀利/共情/专业
结构 = 痛点放大型
```

**Agent层**

input

```
1. 理解需求
2. 确认行业、人群、平台、目的、风格
3. 从知识库检索相似案例、模板、痛点、钩子
4. 生成多个方向
5. 选择一个方向扩写
6. 检查原创度、违禁词、夸大表达
7. 输出多个版本
8. 记录用户反馈，用于优化
```

output

```
选题方向
开头钩子
完整口播文案
分镜建议
标题
评论区引导
可替换版本
风险提醒
```
